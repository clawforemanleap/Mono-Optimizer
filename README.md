# ⚡ Mono — Windows Optimization Utility

A lightweight and clean utility designed to optimize Windows performance, reduce input latency, and boost FPS in games.

## 🚀 Features
- Removes unnecessary background telemetry and bloatware
- Tweaks system responsiveness and decreases input delay
- Optimizes network and gaming settings
- 100% free and safe

## 📥 Download
Download the latest version directly from the **[Releases](../../releases)** tab.

## ⚠️ Note on Antivirus
Some antivirus programs or Windows Defender may flag optimization utilities as a **False Positive** due to registry tweaks and system service modifications. This is normal for tweakers.
